# Portfolio Credit Risk Analysis (SAS Enterprise Guide)

## Overview
This repository contains a SAS script designed to perform portfolio risk segmentation, calculate key credit metrics (EAD, Credit Utilization), and generate risk reporting for decision-making.

## Key Features
* **Data Transformation:** Calculates Exposure at Default (EAD) and Credit Utilization metrics.
* **Risk Segmentation:** Categorizes loans into Risk Bands based on Credit Score and maps estimated Probability of Default (PD).
* **Portfolio Reporting:** Uses `PROC MEANS` to summarize portfolio exposure.
* **Targeted Extraction:** Uses `PROC SQL` to isolate high-risk accounts for monitoring.

## Tech Stack
* SAS Enterprise Guide / Base SAS
* PROC SQL, PROC MEANS, Data Step Processing
